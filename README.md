# playintraffic.ca

Marketing site for [Play in Traffic](https://playintraffic.ca) — three free iOS apps for runners, cyclists, and walkers:

- **Random Run** — running route generator for iPhone + Apple Watch
- **BikeRight** — safest-bike-route navigation with infrastructure safety scoring
- **Go for a Walk** — neighbourhood walking loops with the stops you want

Built with [Eleventy](https://www.11ty.dev/), deployed to GitHub Pages via Actions.

```bash
npm install
npm run serve   # local dev at localhost:8080
npm run build   # production build into _site/
```

See [DEPLOY.md](DEPLOY.md) for the full project layout, image pipeline, and deployment details.
